# 1Accounting (1A)

Приложение для автоматизации бухгалтерии и отчётности.

## Описание

**1Accounting** — это open-source проект, направленный на разработку современного desktop-приложения для автоматизации бухгалтерских процессов, учёта и формирования отчётов.

## Технологический стек

| Компонент | Технология |
|-----------|-----------|
| Backend | Java 26 + Quarkus 3.22 |
| Database | Neo4j (графовая БД) |
| Messaging | Apache Kafka |
| Build Tool | Maven |
| IDE | IntelliJ IDEA |

## Архитектура

- **Клиент-серверная архитектура** через брокер сообщений Apache Kafka
- **Гарантированная доставка документов** с асинхронной проводкой
- **ЭЦП** для подписания документов и управления доступом
- **Многоязычный интерфейс** (русский, казахский, английский)

## Модули приложения

- [x] **Учетная политика** — настройка плана счетов и правил бухгалтерского учёта
- [x] **Налоговая политика** — настройка форм налоговых отчётов
- [x] **Документооборот** — создание, подписание и проводка документов
- [x] **ЭЦП** — электронно-цифровая подпись (ECDSA)
- [x] **Типовые проводки** — автоматическое формирование проводок
- [x] **Управленческие отчёты** — баланс, ОПиУ, оборотная ведомость
- [x] **Календарь событий** — отслеживание сроков отчётности
- [ ] **Платные сервисы** — интеграции (в разработке)
- [ ] **Мобильное приложение** — Android-планшеты (в планах)

## API Endpoints

| Endpoint | Описание |
|----------|----------|
| `GET /api/v1/health` | Проверка работоспособности |
| `GET/POST /api/v1/accounting-policies` | Учетная политика |
| `GET/POST /api/v1/tax-policies` | Налоговая политика |
| `GET/POST /api/v1/documents` | Документы |
| `GET/POST /api/v1/chart-of-accounts` | План счетов |
| `GET /api/v1/reports/*` | Отчёты |
| `GET/POST /api/v1/calendar` | Календарь событий |

## Запуск

```bash
# Установка зависимостей
mvn clean install

# Запуск в dev-режиме
mvn quarkus:dev

# Сборка
mvn package
```

## Требования

- Java 26+
- Neo4j 5.x (bolt://127.0.0.1:7687)
- Apache Kafka (опционально, для продакшена)
- Maven 3.9+
